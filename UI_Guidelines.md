# UI Guidelines

## Animations

- Nunca usar animaciones mayores a 350 ms
- Todas las páginas hacen Fade + Slide
- Los botones usan Scale

## Spacing

## Iconos

Siempre Lucide

No mezclar Material Icons con Heroicons.

## Sombras

Siempre suaves.

Nunca usar sombras negras fuertes.
