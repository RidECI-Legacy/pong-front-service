# RidECI Authentication UI Prompt

## Overview

Design a **premium Login & Registration experience** for the Flutter application **RidECI**.

The design must follow exactly the same visual language as the landing page and the mobile concept shown previously.

The interface should feel like a combination of:

- Apple
- Linear
- Rivian
- Stripe
- Arc Browser

The experience should communicate:

- Trust
- Security
- Modern Technology
- Simplicity
- Community

Avoid generic Material Design login screens.

Everything should feel polished and premium.

---

# General Style

Dark Theme

Large rounded corners (20-28px)

Soft shadows

Glassmorphism

Blue neon accents

Blur backgrounds

Minimal borders

Smooth animations

Plenty of spacing

Premium typography

# Loading State

When the user presses the login button:

Button morphs into a loading capsule.

Circular progress indicator.

Background slightly blurs.

After success:

Button animates into a green check.

Then navigates.

---

# Micro Animations

Animate:

- Cards appearing
- Fields
- Hover
- Focus
- Buttons
- Icons
- Validation
- Page transitions

Everything should feel smooth (250–350 ms).

---

# Mobile Layout

Single column.

Top:

RidECI logo

Animated illustration

Then glass card.

Bottom safe area respected.

Large touch targets.

# UX Details

Use floating labels.

Rounded input fields.

Leading icons.

Password visibility toggle.

Smooth focus transitions.

Animated validation.

Remember last email entered.

Autofill enabled.

---

# Final Goal

The authentication flow should feel like a premium startup product rather than a university system.

The user should immediately perceive RidECI as:

- Safe
- Modern
- Reliable
- Exclusive
- Designed for the Escuela Colombiana de Ingeniería community.

The UI quality should be comparable to apps like Linear, Notion, Revolut, Stripe, Arc Browser, and Apple.
